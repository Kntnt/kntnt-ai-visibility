Read when cutting a release.

Automated ([ADR-0005](../docs/adr/0005-automated-tag-release-stable-asset.md)). Bump the `Version:` header in `kntnt-ai-visibility.php` to `X.Y.Z`, prepare the matching `## [X.Y.Z]` heading in `CHANGELOG.md`, commit, then create and push the tag `vX.Y.Z`. `.github/workflows/release.yml` strips the tag's leading `v` before comparing it with the header, runs `build-release-zip.sh` and publishes `kntnt-ai-visibility.zip` – the version-less name keeps the `latest/download` URL stable. The script also strips the leading `v` to select the matching changelog section for the release notes ([ADR-0011](../docs/adr/0011-release-notes-from-changelog.md)). The build ships a production `vendor/` and excludes tests, CI and dev files.
